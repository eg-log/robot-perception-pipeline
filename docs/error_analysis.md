# 자동 라벨링 오류 분석

## 1. 분석 목적

YOLO11n 기반 자동 라벨링 파이프라인에서 발생하는 객체 미탐 및 추가 탐지 사례를 확인하고, 오류 유형과 발생 가능한 원인을 분석한다.

## 2. 실험 설정

- 모델: YOLO11n
- 데이터: 고정형 CCTV 영상에서 추출한 이미지 18장
- Ground Truth: 자동차 17개
- Confidence Threshold: 0.25
- IoU Threshold: 0.5

## 3. 오류 분석 결과

| 프레임 | TP | FP | FN | 분석 |
|---|---:|---:|---:|---|
| frame_000004 | 0 | 0 | 1 | 화면 오른쪽 경계에 있는 부분 차량 미탐 |
| frame_000007 | 0 | 0 | 1 | 화면 왼쪽 상단의 부분 차량 미탐 |
| frame_000010 | 2 | 1 | 0 | 차량 주변의 추가 예측 박스 발생 |

전체 분석 결과 TP 15개, FP 1개, FN 2개를 기록하였다.

## 4. 원인 분석

**부분 객체 미탐:** 화면 경계에 위치한 차량은 외형의 일부만 관찰할 수 있어, 모델이 객체를 식별할 충분한 특징을 확보하지 못했을 가능성이 있다.

**추가 탐지:** 서로 인접하거나 겹쳐 보이는 차량 주변에서 중복된 예측 박스가 생성되었다. 움직임에 따른 흐림 현상 또한 탐지 결과에 영향을 주었을 가능성이 있다.

다만 이러한 요인은 관찰 결과에 기반한 가설이며, 각각의 원인이 실제 오류를 유발했는지는 추가 실험이 필요하다.

## 5. 개선 방향

1. 부분 객체가 포함된 다양한 이미지에서 탐지 성능 평가
2. 추가 탐지 박스의 IoU와 신뢰도 분석
3. NMS 설정 변경에 따른 탐지 결과 비교
4. 서로 다른 촬영 시점의 도로 영상으로 평가 범위 확장

## 6. 결론

본 실험에서는 YOLO11n을 사용한 자동 라벨링 결과를 사람이 작성한 Ground Truth와 비교하여 오류 사례를 식별하였다.

분석 결과, 화면 경계에서 일부만 보이는 차량의 미탐과 겹친 영역에서의 추가 탐지가 관찰되었다. 이를 통해 자동 생성된 라벨을 그대로 학습 데이터로 활용하기보다 품질 검증과 후처리가 필요하다는 점을 확인하였다.
