
# YOLO 자동 라벨링 실험 기록

## 1. 실험 목적
신뢰도 임계값 변화에 따른 자동차 탐지 성능 비교

## 2. 실험 환경
- 모델: YOLO11n (사전 학습 모델)
- 데이터: CCTV 영상에서 추출한 이미지 18장
- 정답 객체: 자동차 17개
- IoU 기준: 0.5
- 임계값: 0.25, 0.50, 0.75

## 3. 실험 결과

| 임계값 | Precision | Recall | F1-score |
|---|---|---|---|
| 0.25 | 93.8% | 88.2% | 90.9% |
| 0.50 | 92.3% | 70.6% | 80.0% |
| 0.75 | 91.7% | 64.7% | 75.9% |

## 4. 결과 분석
이번 CCTV 데이터에서는 임계값 0.25에서
가장 높은 F1-score를 기록했다.

임계값을 높이면서 미탐지 객체가 증가했으며,
오탐지 개수는 줄어들지 않았다.

## 5. 실험의 한계
- 단일 CCTV 영상 사용
- 평가 이미지가 18장으로 적음
- Ground Truth는 직접 수작업으로 생성
- 다른 도로 환경에 대한 일반화 불가

## 6. 다음 개선 계획
- 오탐·미탐 사례 시각화
- 다양한 영상에서 추가 평가
- 자동 라벨링 파이프라인 개선

## 7. 자동 라벨링 오류 분석

### 분석 환경
- 모델: YOLO11n
- 이미지: CCTV 영상에서 추출한 18장
- Ground Truth: 자동차 17개
- Confidence Threshold: 0.25
- IoU Threshold: 0.5

### 오류 분석 결과
- TP: 15
- FP: 1
- FN: 2
- Precision: 93.8%
- Recall: 88.2%
- F1-score: 90.9%

### 주요 오류 사례

#### frame_000004 / frame_000007
화면 가장자리에 자동차 일부만 나타난 프레임에서
모델이 자동차를 탐지하지 못했다.

가능한 원인:
- 객체의 일부만 촬영됨
- 차량의 형태 정보 부족
- 움직임에 따른 흐림

#### frame_000010
실제 차량 2대에 대해 3개의 예측 박스가 생성되었다.

가능한 원인:
- 동일 객체에 대한 중복 탐지
- 움직임에 따른 객체 윤곽 불명확

### 분석 결과
임계값을 높이면 일부 추가 탐지를 제거할 수 있지만,
동시에 실제 객체를 놓칠 가능성이 증가한다.

이번 데이터에서는 Confidence Threshold 0.25에서
가장 높은 F1-score를 기록했다.

### 개선 방향
1. 화면 가장자리의 부분 객체 탐지 분석
2. 중복 예측 박스의 IoU 검토
3. 다른 촬영 환경의 영상으로 추가 실험
